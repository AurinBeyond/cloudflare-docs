# 📓 Sara · Eesti märkmik

Sinu isiklik loomemärkmik 24 pesa ülevaatuseks.
**Ainult sisemiseks kasutamiseks** — UI jääb 100% inglise.

---

## Kuidas seda mappi kasutada

1. Ava esmalt `SISUKORD.md` — seal on kõik failid loetletud ja viited.
2. Iga maailma jaoks on eraldi fail (`01_…`, `02_…`, `03_…`, `04_…`).
3. Vaata üks maailm korraga. Ära kõike korraga.
4. Sara järjekord on **W1 → W2 → W3 → W4** — see on kasvav järjekord.
5. Iga pesa kohta on 3 rida + lukk: täida iga rida ühe lausega.

## Lukkude tähendus

- 🟢 **LUKUS** — sobib nii nagu on, võib edasi
- 🟡 **MÄRKUSEGA** — väike kohandus vaja, aga kerge
- 🔴 **TAGASI** — vajab uut joonistust või suuremat ümberkirjutamist
- ⚪ **VEEL VAATAMATA**

## Kus pildid ja lehed asuvad

Töökeskkonna URL: `https://aurin-hub.preview.emergentagent.com`

Vaata iga pesa OMA URLil — pilt + tekst koos. Märkmik on lihtsalt sinu kõrvale.

Vaata `kontroll_url_list.md` — seal on iga pesa link valmis.

## Pärast täitmist

Saada täidetud mapp tagasi süsteemi — või jäta lihtsalt enda jaoks. Süsteem ei loe seda automaatselt; otsused tulevad alles siis, kui Sa annad need ise edasi.
