MATRIX AURIN — ATOMS ↔ EMERGENT INTEGRATION PROTOCOL

The goal is to establish a clean and stable collaboration workflow between Atoms (creative/design layer) and the existing Emergent production infrastructure powering Matrix Aurin.

This is NOT a migration.
This is NOT a rebuild.
This is a controlled symbiosis between:

* creative exploration
* stable production implementation

---

## CONFIRMED ROLE SEPARATION

ATOMS RESPONSIBILITY:

* visual direction
* homepage UX
* premium atmosphere
* cinematic layout concepts
* typography
* spacing systems
* emotional positioning
* copywriting refinement
* pricing presentation
* product packaging
* marketing concepts
* campaign visuals
* frontend component ideas

ATOMS MUST NOT:

* modify backend systems
* replace production infrastructure
* change MongoDB logic
* alter ElevenLabs voice systems
* modify payments/webhooks
* rebuild routing/auth/session systems
* redesign production architecture

---

## EMERGENT RESPONSIBILITY

EMERGENT handles:

* production deployment
* FastAPI/backend
* MongoDB
* ElevenLabs infrastructure
* room/session systems
* routing/auth
* payments/runtime stability
* live production integration

Emergent will implement approved frontend specs exactly as provided, without redesigning or second-guessing the visual direction.
