# Project Summary
The Matrix Aurin House is a web-based product ecosystem designed to provide users with a seamless experience across five interconnected wings. These wings offer both luxury premium content and open discovery resources, fostering a nurturing environment for emotional growth and exploration. The platform focuses on creating an elegant visual distinction between free and paid offerings, ensuring users can navigate fluidly without confusion.

# Project Module Description
- **Luxury Landing**: The premium entry point featuring curated collections and a refined aesthetic.
- **Open Library**: A free resource directory offering various educational materials and activities.
- **Kids Universe**: A playful space designed for children, featuring age-specific activities and creative packages.
- **Quiet Store**: A premium store offering curated products, memberships, and gift cards.
- **Voice House**: An immersive audio experience with guided sessions for deep presence and relaxation.

# File Description Inventory
- **README.md**: Provides project setup and usage instructions.
- **components.json**: Defines the components used in the project.
- **eslint.config.js**: Configuration for linting JavaScript/TypeScript files.
- **image_manifest.json**: Contains metadata for generated images.
- **index.html**: The main HTML file for the application.
- **package.json**: Lists dependencies and scripts for the project.
- **postcss.config.js**: Configuration for PostCSS processing.
- **prerender/**: Contains scripts for pre-rendering pages.
- **public/**: Directory for public assets like images and icons.
- **site.config.json**: Configuration settings for the site.
- **src/**: Contains all source code for the application, including components, hooks, and styles.
- **tailwind.config.ts**: Configuration file for Tailwind CSS.
- **tsconfig.*.json**: TypeScript configuration files for different aspects of the project.
- **vite.config.ts**: Configuration for Vite, the build tool used.

# Technology Stack
- **React**: JavaScript library for building user interfaces.
- **TypeScript**: Superset of JavaScript for type safety.
- **Vite**: Fast build tool and development server.
- **Tailwind CSS**: Utility-first CSS framework for styling.
- **shadcn/ui**: UI component library for building consistent interfaces.
- **Lucide React**: Icon library for React applications.

# Usage
1. Install dependencies:
   ```
   pnpm install
   ```
2. Build the project:
   ```
   pnpm run build
   ```
3. Start the development server:
   ```
   pnpm run dev
   ```
