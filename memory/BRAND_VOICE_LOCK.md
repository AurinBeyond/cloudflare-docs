## The 80/20 Rule

**`[brackets]` are the spice. Serif-italic is the meat.**
**Never flip the ratio.**

If the code-language (brackets, system-call terminology, error-codes)
becomes the dominant voice instead of the accent voice, Matrix Aurin
collapses from "elite biomechanical house" into "crypto-bro
SaaS pitch deck". The aesthetic value of the technical register comes
**from its rarity inside the serif-italic field**, not from saturation.

## Tier 2 — Bracket code-tags (use sparingly, max 1–2 per surface)

These are the **gold-thread accents**. ONE per page, MAXIMUM two on
heavy-stakes surfaces (landing, modal). Never stacked back-to-back.

Existing canonical uses:
- `[ Protocol · The Sovereign Code ]` — manifest eyebrow
- `[ TRANSMISSION GATE: PARENTS' ROOM ]` — Sara modal eyebrow
- `[ 01 · diagnostic ]` ... `[ 07 · diagnostic ]` — Subsystem markers
- `[ Sub-cluster ]` — sub-navigation marker
- `[ Season 2 · forthcoming ]` — pending features

Permitted future uses:
- Email-transmission subject prefixes (one per email)
- Instagram/LinkedIn single-card headlines (one per post)
- Admin/operational status indicators

## Tier 3 — BANNED constructions (do not ship)

These are the patterns that turn the platform into LARP:

- ❌ `[ ERROR_CODE: NO_BLIND_TRUST ]` and similar fake-error-code
  framing in body copy. Errors aren't a brand register — they read
  as a tech-startup costume.
- ❌ `[ PROTOCOL LAB / CORE RESTORE ]` and other forward-slash code
  stacks. Reads as crypto-bro Twitter aesthetic.
- ❌ Multiple code-tags in a single paragraph or heading.
- ❌ Fixed-width / monospace fonts in body prose. Cormorant Garamond
  Serif IS the brand. Monospace is permitted only inside `<code>` /
  `<pre>` blocks in code documentation, never in product UI.
- ❌ Russian source-mantras quoted alone, without their English
  Matrix Aurin translation directly adjacent.
- ❌ Therapy / wellness language anywhere (heal, cure, treat,
  patient, journey, holistic, transformative).
- ❌ Pedagogical language anywhere (lesson, student, teacher,
  curriculum, course material).
- ❌ "Puberty" — permanently retired. Always "The Subsystem".

## Tier 4 — Curator voice rules (the rooms themselves)

Inside Kaelan / Grace / Sara / Alistair rooms, the proportion shifts
**HARDER toward serif-italic prose**. Each curator carries the
biomechanical register through full sentences, never through
code-tags. Their content is body, not signal.

Rule of thumb for room content:
- Up to **one** bracket marker per page (usually an eyebrow tag)
- Zero bracket markers inside the actual transmission body
- Zero fake-error syntax
- All technical metaphors woven into natural sentence rhythm

Reference: "The Broken Clockwork" letters 1–7 in `SEED_COURSES` are
the canonical example. Re-read them when in doubt.

## When in doubt

1. Read the surface aloud.
2. If it sounds like it could be on a SaaS landing page → too many brackets.
3. If it sounds like a meditation app → too soft, add register.
4. If it sounds like a private letter from a senior architect to
   another senior architect → ✓ correct frequency.
