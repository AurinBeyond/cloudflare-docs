## How to use this file

After each outreach action, update the row:
- `sent` — date you sent the DM/email
- `replied` — Y / N / "interested" / "ghosted"
- `gifted` — Y / N (whether they accepted free PDF + audio access)
- `posted` — Y / N + link to the post if they shared
- `notes` — brief observation (e.g. "warm reply, no commitment", "wants exclusivity")

**Discipline:** if a name does not reply within 14 days, mark `ghosted` and move on. Do not chase. The pitch is anti-marketing — silence is a valid answer.
