## Founder-authored Estonian refinement script (verbatim)

### Entry page (/beginning)
```
Sa ei pea kõike korraga mõistma.
Mõnikord piisab ühest sammust.

→ Begin
```

### Day 1 — STOP
**Intro:**
```
Mõnikord ei ole vaja edasi minna.
Piisab, kui Sa korraks peatad.
```
**End / pause copy:**
```
Sa ei pea kiirustama.
Jätka homme.
```

### Day 2 — NOTICE
**Intro:**
```
Kui Sa ei kiirusta…
hakkavad ilmuma asjad, mida varem ei märganud.
```
**End:**
```
Lase sellel settida.
Jätka homme.
```

### Day 3 — PATTERN
**Intro:**
```
Mõned asjad korduvad.
Mitte juhuslikult.
```
**End:**
```
Sa ei pea seda muutma.
Veel mitte.
Jätka homme.
```

### Day 4 — DISTANCE
**Intro:**
```
Sa oled siin…
aga kõik ei pea Sinuga kaasa tulema.
```
**End:**
```
Natuke ruumi võib muuta palju.
Jätka homme.
```

### Day 5 — RELEASE
**Intro:**
```
Sa ei pea lahti laskma.
Piisab, kui Sa lõpetad hoidmise.
```
**End:**
```
Midagi juba muutub.
Jätka homme.
```

### Day 6 — SPACE
**Intro:**
```
Kui midagi kaob…
tekib ruum.
```
**End:**
```
Sa võid selles ruumis olla.
Jätka homme.
```

### Day 7 — RETURN
**Intro:**
```
See ei ole lõpp.
Midagi lihtsalt nihkub.
```
**End:**
```
Kui see puudutas Sind…
siis Sa ei ole enam päris samas kohas.
Ja mõnikord sealt edasi minnakse
vaikselt.
```
